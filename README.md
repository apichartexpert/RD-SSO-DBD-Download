# TaxDocs — ดาวน์โหลดและจัดเก็บแบบภาษี / ใบเสร็จรับเงิน

รองรับ **กรมสรรพากร** (ภ.ง.ด.1, 1ก, 2, 3, 53, 54, 50, 51, ภ.พ.30, ภ.พ.36, ภ.ธ.40, อ.ส.4ข),
**ประกันสังคม** (สปส.1-10, กท.20ก) และ **DBD e-Filing** (งบการเงิน, ส.บช.3, บอจ.5)
ทั้งแบบที่ยื่น, ใบเสร็จรับเงิน, ใบแจ้งชำระ และใบรับการยื่น — แล้วจัดเก็บเป็นโฟลเดอร์ตามบริษัท/ปี/หน่วยงาน/แบบ พร้อมตั้งชื่อไฟล์ให้อัตโนมัติ

> *Local web app for Thai accountants: captures tax forms and receipts downloaded from the Revenue Department, Social Security Office and DBD e-Filing, then classifies, renames and files them. Runs only on your own computer.*

## ติดตั้ง (ครั้งแรกครั้งเดียว — Windows)
1. ติดตั้ง Python 3.10 ขึ้นไป จาก [python.org](https://www.python.org/downloads/) (ติ๊ก **Add Python to PATH** ตอนติดตั้ง)
2. ดาวน์โหลดโปรแกรม: ที่หน้า GitHub นี้ กดปุ่มสีเขียว **Code → Download ZIP** แล้วแตกไฟล์
   (หรือ `git clone` ถ้าใช้ git เป็น)
3. ดับเบิลคลิก `setup.bat` (ติดตั้งไลบรารีและเบราว์เซอร์ ใช้เวลาไม่กี่นาที)
4. ดับเบิลคลิก `run_web.bat` แล้วตั้งค่าบริษัทและโฟลเดอร์ในหน้าเว็บ

อัปเดตเวอร์ชันใหม่: ดาวน์โหลด ZIP ใหม่มาวางทับ — ค่าตั้ง (`config.yaml`) ไม่ถูกเขียนทับ

## วิธีใช้แบบหน้าเว็บ (แนะนำ)
ดับเบิลคลิก `run_web.bat` → หน้าเว็บ http://127.0.0.1:8765 จะเปิดขึ้นเอง (ทำงานบนเครื่องนี้เท่านั้น ไม่ส่งข้อมูลออกไปที่ใด)
1. **โฟลเดอร์ปลายทาง** — กด "เลือกโฟลเดอร์…" จะเปิดหน้าต่างเลือกโฟลเดอร์ของ Windows (สร้างโฟลเดอร์ใหม่ได้)
   หรือพิมพ์ path ลงในช่องแล้วกด Enter · ค่าเริ่มต้นคือไดรฟ์ `I:\` ถ้าเครื่องมี ไม่มีก็ใช้ `Documents\TaxDocs`
2. **บริษัท** — เพิ่มชื่อบริษัทและเลขผู้เสียภาษี 13 หลัก (เพิ่มได้หลายบริษัท)
3. แท็บ **ดาวน์โหลดจากเว็บ** — มีการ์ด 3 ใบ: **RD** กรมสรรพากร · **SSO** ประกันสังคม · **DBD** กรมพัฒนาธุรกิจการค้า
   - กด **"เปิดเว็บไซต์เพื่อเข้าสู่ระบบ →"** ในการ์ดใดก็ได้ หน้าเข้าสู่ระบบของหน่วยงานนั้นจะเปิดใน Microsoft Edge
   - ใส่ชื่อผู้ใช้/รหัสผ่านด้วยตัวเอง แล้วกดดาวน์โหลดหรือเปิด PDF ตามปกติ — ไฟล์เข้าคิวทันที
   - หรือติ๊กเลือกหลายเว็บแล้วกด "เปิดทุกเว็บที่เลือก" (เปิดเป็นแท็บแยก)
   - ถ้าเว็บราชการเปลี่ยนที่อยู่ กด "แก้ลิงก์" ในการ์ดเพื่อใส่ลิงก์ใหม่
4. แท็บ **จัดไฟล์ที่มีอยู่** — เลือกโฟลเดอร์ต้นทาง (เช่น Downloads) ระบบจะอ่านและจัดหมวด PDF ทั้งหมด
5. **คิวเอกสาร** — ทุกไฟล์ขึ้นในคิวพร้อมแบบ/ประเภท/งวด/บริษัทที่ระบบอ่านได้ แก้ไขได้ในช่อง คลิกเพื่อดูตัวอย่าง PDF แล้วกด "บันทึก"
   ปุ่ม "บันทึกทั้งหมดที่มั่นใจ" จะบันทึกเฉพาะรายการที่ไม่มี ⚠
6. แท็บ **ประวัติการบันทึก** — ดู 50 ไฟล์ล่าสุดที่บันทึกแล้ว

ปิดหน้าต่างดำ (command prompt) เพื่อหยุดโปรแกรม

## วิธีใช้แบบบรรทัดคำสั่ง
คัดลอก `config.example.yaml` เป็น `config.yaml` แล้วแก้ชื่อบริษัท/โฟลเดอร์ก่อน

**ดาวน์โหลดจากเว็บ** — ดับเบิลคลิก `run_download.bat`
1. เบราว์เซอร์จะเปิดเว็บสรรพากร, ประกันสังคม, DBD ให้ (คนละแท็บ)
2. ล็อกอินด้วยตัวเอง (รหัสผ่าน / OTP / CAPTCHA) — โปรแกรมไม่เก็บรหัสผ่าน
3. ไปที่หน้าประวัติการยื่นแบบ/พิมพ์ใบเสร็จ แล้วกดดาวน์โหลดหรือเปิด PDF ตามปกติ
4. ทุกไฟล์ถูกดักจับ จัดหมวด ตั้งชื่อ แล้วบันทึกทันที (หน้าต่างดำจะถามยืนยัน)
5. ปิดเบราว์เซอร์เมื่อเสร็จ

ครั้งต่อไป session ล็อกอินอาจยังอยู่ (ขึ้นกับเว็บแต่ละแห่ง)

**จัดระเบียบไฟล์ที่ดาวน์โหลดไว้แล้ว** — ดับเบิลคลิก `run_sort.bat` (อ่านจากโฟลเดอร์ Downloads, คัดลอกไม่ลบต้นฉบับ)
หรือ `python taxdocs.py sort "D:\โฟลเดอร์เก่า" --move` เพื่อย้ายไฟล์

เลือกเฉพาะบางเว็บ: `python taxdocs.py download --portal rd` (rd / sso / dbd)

## โครงสร้างโฟลเดอร์
```
<output_root>/
└── 0105500000000_บริษัท ตัวอย่าง จำกัด/
    ├── index.csv                         ← ทะเบียนไฟล์ทั้งหมด (เปิดด้วย Excel ได้)
    └── 2569/
        ├── 01_สรรพากร/
        │   ├── ภงด1/   2569-09_ภงด1_แบบยื่น_0105500000000.pdf
        │   ├── ภงด3/   2569-09_ภงด3_ใบเสร็จ_0105500000000.pdf
        │   ├── ภงด53/
        │   ├── ภพ30/
        │   └── ภงด50/  2569_ภงด50_แบบยื่น_0105500000000.pdf
        ├── 02_ประกันสังคม/
        │   ├── สปส1-10/
        │   └── กท20ก/
        └── 03_DBD_งบการเงิน_ผู้ถือหุ้น/
            ├── งบการเงิน/
            ├── สบช3/
            └── บอจ5/
```
ชื่อไฟล์: `ปี-เดือน_แบบ_ประเภท_เลขผู้เสียภาษี.pdf` (แบบรายปีใช้ปีอย่างเดียว)
ไฟล์ซ้ำ (เนื้อหาเหมือนกัน) จะถูกข้าม ส่วนไฟล์ชื่อซ้ำแต่เนื้อหาต่าง (เช่น ยื่นเพิ่มเติม) จะต่อท้าย `_v2`, `_v3`

## ระหว่างยืนยัน
`Enter` บันทึก · `f` เปลี่ยนแบบ · `k` เปลี่ยนประเภท · `p` แก้งวด (เช่น `2569-09`) · `c` เปลี่ยนบริษัท · `o` เปิดดูไฟล์ · `s` ข้าม
บรรทัดที่มี ⚠ แปลว่าระบบเดางวดภาษี ควรตรวจก่อนกด Enter
เมื่อมั่นใจแล้ว ตั้ง `confirm_each_file: false` เพื่อให้บันทึกอัตโนมัติ

## ข้อจำกัด
- การล็อกอินต้องทำเอง (เว็บราชการใช้ OTP/CAPTCHA และไม่ควรเก็บรหัสผ่านไว้ในโปรแกรม)
- การจัดหมวดอ่านจากข้อความใน PDF + ชื่อไฟล์ PDF ที่เป็นภาพสแกนอ่านข้อความไม่ได้ → เลือกเองด้วย `f`/`p`
- โฟลเดอร์ `browser_profile` เก็บ session การล็อกอิน — อย่าแชร์ให้ผู้อื่น
- ผลการจัดหมวดเป็นการอ่านอัตโนมัติ ผู้ใช้ควรตรวจสอบก่อนนำไปใช้อ้างอิง

## ความเป็นส่วนตัว
โปรแกรมทำงานบนเครื่องผู้ใช้เท่านั้น (เปิดที่ 127.0.0.1) ไม่ส่งเอกสาร รหัสผ่าน หรือข้อมูลบริษัทไปที่ใด
ไฟล์ `config.yaml`, `browser_profile/` และเอกสารที่ดาวน์โหลด ไม่ถูกรวมใน repository นี้ (ดู `.gitignore`)
